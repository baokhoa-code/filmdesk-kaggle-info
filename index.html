FilmDesk Kaggle is a personal workflow connecting Google Drive, a user-run Kaggle notebook, and the FilmDesk desktop app.

The Kaggle integration is being configured and tested. This site explains its intended operation and data practices; it does not provide a hosted processing service.

Source files → Google Drive → Kaggle processing → FilmDesk review

What the workflow does

The notebook is designed to read episode videos and source metadata from an input folder selected by the owner, process video orientation and audio, create an editing master and a smaller review video, and save the results to an output folder. A separate log folder records processing status and recovery checkpoints.

The owner imports the resulting package into FilmDesk for manual review and editing. Google Drive for desktop synchronizes the selected folders with the owner's computer.

Why Google Drive access is requested

OAuth authorizes the workflow to list and download input files and to create or update output files, logs, and checkpoints. The Drive permission requested can technically access the account's Drive files; the configured workflow limits its work to the owner's selected folders. Folder IDs do not narrow the OAuth permission itself.

The owner stays in control

The owner starts the notebook and chooses the folders. Source descriptions are preserved, including empty descriptions. The connector does not automatically publish videos to YouTube or approve copyright claims or content review.
